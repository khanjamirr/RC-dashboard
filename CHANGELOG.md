# Changelog

## 2.0

- Complete redesign: top navigation with all nine pages, a single filter bar, and a slide-out data panel.
- Every chart can switch to a table; every card and table can be copied straight into Excel or Sheets.
- Global Charts/Tables switch (shortcut `T`) and page shortcuts (`1`–`9`).
- Auto-written page summaries and one-line takeaways on each chart.
- Headline numbers compare against the previous period of the same length, with daily trend lines.
- New charts: highest and lowest scores, performance groups, score spread, how each person's calls end, score breakdown, weekday pick-up and call length per recruiter.
- New table columns: real-conversation rate, people reached per day, idle minutes, attendance rate, instant hang-ups, average talk time, and a per-recruiter inbound table.
- Lines and shaded bands no longer spill outside charts when an hour has very few calls.
- Works on phones.
- Existing saved data and settings from 1.x load automatically.
