# Changelog

## 2.1

- Add many exports at once (e.g. six files). Overlapping files are merged: a call that appears in several files is counted once, matched on time, recruiter, numbers, length and result. Files with the same name are kept side by side instead of replacing each other, and a file that is already fully loaded is skipped.
- Removing a file keeps the calls that your other files also cover.
- Working days are now a setting (Settings → Working days). Business hours shows the days and times it uses.
- Every table can be sorted by clicking a column heading, including the table view of every chart. Copy follows the sort order.
- Profile: the person is chosen from the recruiter picker in the filter bar (the extra picker on the page is gone). Day by day now compares their real-conversation rate with the team each day and names the dates worth discussing; the weekday chart lists every date behind each bar.
- Cleaner pages: each page opens with up to three plain-language insights, shows only its key charts, and tucks the rest under “Show more detail”.

## 2.0

- Complete redesign: top navigation with all nine pages, a single filter bar, and a slide-out data panel.
- Every chart can switch to a table; every card and table can be copied straight into Excel or Sheets.
- Global Charts/Tables switch (shortcut `T`) and page shortcuts (`1`–`9`).
- Auto-written page summaries and one-line takeaways on each chart.
- Headline numbers compare against the previous period of the same length, with daily trend lines.
- New charts: highest and lowest scores, performance groups, score spread, how each person's calls end, score breakdown, weekday pick-up and call length per recruiter.
- New table columns: real-conversation rate, people reached per day, idle minutes, attendance rate, instant hang-ups, average talk time, and a per-recruiter inbound table.
- Lines and shaded bands no longer spill outside charts when an hour has very few calls.
- Works on phones.
- Existing saved data and settings from 1.x load automatically.
